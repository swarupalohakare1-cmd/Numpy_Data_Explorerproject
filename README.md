# NumPy Data Explorer

This is a project from my Data Science internship.

It shows basic NumPy operations like:
- Creating arrays from file data
- Indexing and slicing
- Mathematical operations
- Statistical operations
- Row-wise and column-wise operations
- Reshaping arrays
- Saving and loading arrays
- Comparing NumPy arrays with Python lists

## How to Run
1. Make sure Python is installed
2. Install NumPy: `pip install numpy`
3. Place `data.txt` in the same folder
4. Run: `python numpy_data_explorer.py`
